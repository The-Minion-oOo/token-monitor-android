# Community conduct

Be respectful, specific and constructive. Discuss code and behavior without
personal attacks, harassment, threats, discriminatory language or unwanted
personal attention. Respect other people's privacy and use synthetic data in
shared reports and screenshots.

Maintainers may edit or remove contributions, lock discussions or restrict
participation when needed to keep the project welcoming and safe. For a concern
about conduct, request a private contact channel without posting personal details
or reproducing abusive material in a public issue.

These expectations apply in this repository's issues, pull requests and other
project-managed spaces.
