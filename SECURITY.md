# Reporting security concerns

Supported compatibility baseline: desktop Token Monitor v0.54.0. Fixes are prepared
for the newest Android revision; older APKs are not separately maintained.

Do not post Hub secrets, private addresses, account details, raw Hub responses or
working exploits in public issues. Use **Security → Report a vulnerability** when
private reporting is available on this repository. If it is unavailable, open a
minimal issue requesting a private reporting channel without describing the
vulnerability or including sensitive attachments.

Private vulnerability reporting must be enabled before public launch. No
response-time guarantee is made.

The app's data, transport, storage and permission boundaries are documented in
[Security and privacy](docs/SECURITY.md).
