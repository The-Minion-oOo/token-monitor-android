# Android v0.93.1 r2

I updated **Limits** to show the separate accounts and quota products reported by newer Hubs. When the Hub shares account names and order from the desktop, Android shows those names on Home and Limits and follows the desktop order within each provider on Limits.

Alibaba Cloud rows distinguish the Bailian and Model Studio plans. OpenCode quota windows identify Go and Zen when the Hub reports the product. Desktop v0.93.1 remains the verified compatibility baseline.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
