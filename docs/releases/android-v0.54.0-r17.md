# Android v0.54.0 r17

- Labels the active Tailscale, home Wi-Fi, or private-network route.
- Adds an Appearance option that follows the phone's light and dark mode.
- Distinguishes same-named limit windows by period on Home, Limits, and widgets.

Compatible with Android 8.0+ and desktop Token Monitor v0.54.0. Install over the
existing release to preserve pairing; see [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
