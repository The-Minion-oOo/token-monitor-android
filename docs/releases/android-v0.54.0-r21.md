# Android v0.54.0 r21

- Keeps immediate dashboard updates while reducing widget Live traffic to one
  lightweight stats refresh every 30 seconds.
- Updates the Live notification only when the information shown has changed.
- Completes queued cache writes before repository shutdown.

Compatible with Android 8.0+ and desktop Token Monitor v0.54.0. Install over the
existing release to preserve pairing; see [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
