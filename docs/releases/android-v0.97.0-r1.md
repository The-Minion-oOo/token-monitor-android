# Android v0.97.0 r1

I updated Android for desktop Token Monitor v0.97.0. In **Sessions**, choose **Newest** to find recently active conversations or **Most tokens** to keep the highest-usage conversations first. Groups keep their combined totals in both views.

**Limits** shows the reported Notion AI Standard and Select credits as separate pools. **Settings → Hub status** identifies built-in and standalone Node Hubs when they report their deployment type.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the signed upgrade on an Android 8 emulator. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
