# Android v0.98.0 r1

I updated Android for desktop Token Monitor v0.98.0 and brought the desktop’s Settings cards to the phone. Each card has a larger tap area, an icon, and room for its current value. Tap a card to open its controls.

On Home and Sessions, untitled conversations use the project name when **Show session titles** is on. Shared titles still take priority. Android continues to calculate its history ranges from daily Hub history.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the signed upgrade on an Android 8 emulator and the Settings cards on Android emulators. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
