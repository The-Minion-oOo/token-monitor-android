# Android v0.94.0 r1

I updated Android for desktop Token Monitor v0.94.0. When your Hub shares account names, they appear on **Home** and **Limits**. The Limits page follows the desktop order within each provider, and accounts like DeepSeek and Factory keep their own quota readings.

Alibaba Cloud distinguishes Bailian and Model Studio plans. OpenCode shows Go and Zen on quota windows that report a product. You can manage account names, order, and credentials on desktop.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
