# Android v0.90.0 r1

I updated Android for desktop Token Monitor v0.90.0.

- See Hark’s daily and monthly allowances in Limits. Any reported top-up
  spend appears separately in dollars.
- See personal and team Qoder credits with their own reset times when the
  Hub reports both.
- Home shows lifetime active days when the Hub has complete history. The
  activity grid still shows recent days.
- Inkling models use the Thinking Machines mark.

Use **Settings → App updates**, or install the signed APK over your current
copy. Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the released Node and Worker Hubs and tested the Android build on
emulators. I haven’t tested this build on my phone.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
