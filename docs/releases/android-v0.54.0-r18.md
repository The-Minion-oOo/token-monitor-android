# Android v0.54.0 r18

- Replaces the widget button row with compact Refresh and Live controls.
- Uses the recovered space for messages, active time, streak, tool share, quota
  windows, and seven-day totals as each widget size permits.

existing release to preserve pairing; see [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
