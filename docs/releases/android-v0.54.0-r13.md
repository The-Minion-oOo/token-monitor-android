# Android v0.54.0 r13

- Redesigns five responsive widget layouts with dashboard typography, size-aware
  charts, full counters, Refresh, and bounded one-hour Live mode.
- Adds tool-filtered model pages, heatmap day details, usage search, period
  comparisons, and denser dashboard lists.
- Improves snapshot recovery, stream cancellation, retained device history, and
  shared repository ownership between the app and widgets.

Compatible with Android 8.0+ and desktop Token Monitor v0.54.0. Install over the
existing release to preserve pairing; see [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).
