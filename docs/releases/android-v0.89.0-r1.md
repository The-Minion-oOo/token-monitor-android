# Android v0.89.0 r1

I updated Android for desktop Token Monitor v0.89.0.

- Home and Sessions show the last-used model reported for Codex and Claude.
  Grouped conversations use the latest main continuation and keep each model's
  token breakdown. A model can appear as last used before it has any recorded tokens.
- Gemini CLI usage appears under the desktop name with the token totals reported
  by the Hub.

Use **Settings → App updates**, or install the signed APK over the current copy.
Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the released Node and Worker Hubs and tested the Android build on
emulators. I haven't phone-tested this build.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
