# Android v0.92.0 r1

I updated Android for desktop Token Monitor v0.92.0.

- Limits shows the quota and sign-in status for each Copilot account the Hub reports.
- DeepSeek Search and Fetch fees appear in Limits in their reported currency when the desktop Hub supplies them.
- I verified live updates against the released Node Hub and Worker, including replaying the Worker’s slow-connection recovery on Android.

Use **Settings → App updates** to install this release. Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I tested the signed update on an emulator.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
