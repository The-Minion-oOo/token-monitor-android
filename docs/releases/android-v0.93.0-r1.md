# Android v0.93.0 r1

I updated Android for desktop Token Monitor v0.93.0. Usage from the international edition appears as **Qoder**, and usage from the China edition appears as **Qoder CN**. Each has its own totals and sessions when the Hub reports both.

I checked that the released Worker closes an old stream after replacement and that Android can read the new snapshot.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I tested the signed update on an emulator. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
