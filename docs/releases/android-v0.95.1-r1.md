# Android v0.95.1 r1

I updated Android for desktop Token Monitor v0.95.1. Usage from **Junie** and **OpenCodeReview** now appears under each tool’s name and icon.

**Limits** distinguishes Qoder CN from global Qoder. When the Hub reports separate Qoder accounts or GLM Team projects, their quotas stay in separate rows. Recent Grok Build, WorkBuddy, and CatPaw sessions show context remaining when the desktop reports it.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the signed upgrade on an Android 8 emulator. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
