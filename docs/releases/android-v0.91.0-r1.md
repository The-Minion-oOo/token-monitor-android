# Android v0.91.0 r1

I updated Android for desktop Token Monitor v0.91.0.

- Choose AUD, CAD, CHF, GBP or SGD for estimated usage costs under **Settings → Display currency**.
- Subscription and top-up amounts keep their recorded currency. JPY and KRW appear in whole units, and the other supported currencies show two decimals.
- Home and Limits show Cursor’s included quota as Weekly or Monthly according to the period the Hub reports.

Use **Settings → App updates** to install this release. Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the released Node and Worker Hubs and tested the Android build on emulators. I haven’t tested this build on my phone.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
