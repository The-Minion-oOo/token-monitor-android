# Android v0.93.1 r1

I updated Android for desktop Token Monitor v0.93.1. In **Projects**, new usage from a linked Git worktree appears under its parent project when the Hub reports it there. The combined total includes usage from both checkouts, and their sessions are still listed separately.

This update also works with the quota and usage readings sent by the desktop release, which restores Muse web quotas and picks up OpenClaw usage found in archived transcripts.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I tested the signed update on an emulator. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
