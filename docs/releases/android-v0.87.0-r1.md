# Android v0.87.0 r1

I updated the Android companion for desktop Token Monitor v0.87.0.

## What's new

- **OpenDesign limits.** See the workspace's five-hour and weekly allowances,
  with reset times when the Hub reports them.
- **More service status.** Check OpenCode, Factory Droid, Kimi, Copilot, Zed,
  Devin and MiniMax in both regions. Copilot reports incidents for its own
  GitHub components.
- **Desktop sync.** I verified that Android reads zero totals and corrected
  history after desktop delta uploads to the Node Hub and Worker.

## Updating

Use **Settings → App updates**, or install the signed APK over the current
copy. Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the released Hub and Worker with synthetic data. Release checks are
in progress.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
