# Android v0.99.0 r1

I updated Android for desktop Token Monitor v0.99.0. Home and Sessions now show fresh Antigravity activity reported by the Hub, so a turn can stay marked as running between token updates. Related Antigravity and Kiro runs appear together when the Hub identifies them as part of the same T3 Code thread.

I checked that Android can still read the recorded session rows and activity calendar after a compact Hub upload. Android uses daily history for its date ranges.

Use **Settings → App updates** to install this release. Android 8 or newer is required. [Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the signed upgrade on an Android 8 emulator. I haven’t tested this build on my phone. [Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
