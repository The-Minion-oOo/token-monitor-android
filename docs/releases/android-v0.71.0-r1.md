# Android v0.71.0 r1

I updated the Android companion for desktop Token Monitor v0.71.0.

## What's new

- Goose usage appears with its desktop name and mark, including reported
  models, sessions and costs.
- Notion AI shows its Rolling and Monthly allowances and Business/Enterprise
  plan. Separate workspaces remain separate accounts.
- WorkBuddy accounts keep their own quota and sign-in state. I checked the
  new multi-account records against the released Hub.

Digit roll, session grouping, network route rules and widget layouts are
unchanged. WorkBuddy sign-in and combined quotas, Notion configuration and
session transcript details stay on desktop; Android is still read-only.

## Updating

I signed this APK with the same release key and increased the version code to
710001. Use **Settings → App updates**, or install the release APK over the
existing app without uninstalling. Android asks you to confirm installation.
Android 8 or newer is required.
[Install and update](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/INSTALL.md).

I checked the pinned Hub, JVM tests, lint, builds and emulator presentation.
I haven't tested this release on my phone, and battery use is not measured.
[Validation](https://github.com/The-Minion-oOo/token-monitor-android/blob/main/docs/VALIDATION.md).
